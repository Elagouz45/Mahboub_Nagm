# Mahboub Nagm Website Image Pack

A cohesive image pack created for the Arabic electrical-appliances ecommerce website **محبوب نجم للأجهزة الكهربائية**.

## Contents

- 6 homepage and campaign banners — 1600×900 WebP
- 10 category images — 1000×1000 WebP
- 24 product images — 1000×1000 WebP
- 6 lifestyle images — 1600×900 WebP
- 4 trust and service images — 1000×1000 WebP
- 1 preview contact sheet — for reviewing the pack only
- `assets-manifest.json` — exact file purpose and dimensions
- `CURSOR-INSTRUCTIONS.md` — integration instructions

The 50 website images are stored in the five named folders. The preview sheet is not counted as a website asset.

## Brand direction

The images were created to match the approved website direction:

- premium and trustworthy;
- modern and commercial;
- deep navy, off-white, brushed steel and restrained warm-orange accents;
- clean compositions suitable for Arabic RTL layouts;
- no intentional third-party logos or readable brand labels.

## Usage

Copy the five image folders into the Angular project's image assets directory while preserving filenames. Use `assets-manifest.json` to identify the intended placement of each image.

Product and category images are square. Banner and lifestyle images are landscape. All filenames use kebab-case.
