# رحلة المتجر التجريبية

هذه النسخة تعمل محليًا بدون خادم أو دفع فعلي. بيانات المنتجات موحدة مع الكتالوج، والحسابات والطلبات ورسائل التواصل محفوظة في المتصفح فقط.

## تجربة الرحلة

1. افتح منتجًا من المتجر، اختر الكمية وأضفه للسلة.
2. عدّل الكمية أو احذف منتجات، ثم انتقل لإتمام الطلب.
3. أكمل كضيف أو سجّل الدخول. يمكن اختيار عنوان محفوظ أو حفظ عنوان جديد.
4. اختر المحافظة، ثم راجع الشحن والدفع عند الاستلام وأكد الطلب التجريبي.
5. احتفظ برابط التأكيد. الطلب يظهر في حساب المستخدم الذي أنشأه؛ طلب الضيف متاح في نفس المتصفح بوضع الضيف.
6. من التواصل، اختر طلب صيانة أو استفسارًا واحفظ الرسالة. رابط التفاصيل والرقم المرجعي يسمحان بالرجوع إليها، وتظهر الصيانة في حساب صاحبها.

لا توجد لوحة إدارة، ولا انتقال تلقائي إلى «تم الشحن» أو «تم التسليم». المرفقات غير مدعومة، وقنوات الهاتف وواتساب غير المضبوطة لا تظهر كأزرار تواصل.

## قواعد البيانات المحلية

- إعدادات الشحن والحد الأقصى للكمية في `src/app/core/config/demo-commerce.config.ts`: الشحن 100 جنيه لكل محافظة مدرجة، والكمية القصوى 10 لكل SKU.
- `mahbub-najm.commerce.v1` يجمع السلال والمفضلة والطلبات والرسائل في سجل بإصدار. تتم مراجعة شكل البيانات عند القراءة، ويُستورد التخزين القديم للسلة والمفضلة عند عدم وجود السجل الجديد.
- إنشاء الطلب وتفريغ السلة يحدثان في كتابة واحدة؛ فشل الحفظ يبقي السلة. مفتاح محاولة التأكيد يمنع تكرار الطلب نفسه.
- الطلب يحتفظ بنسخة من العنوان والأسعار والمنتجات. تغير السعر قبل التأكيد يتطلب مراجعة جديدة؛ المنتج غير المتاح يمنع التأكيد.
- تُدمج سلة الضيف ومفضلته بالحساب عند الدخول، وتُفصل بيانات الحسابات عند التبديل. هذا فصل لتجربة العرض المحلية، وليس نظام صلاحيات لخادم.
- حذف بيانات المتصفح يحذف هذه البيانات. لا توجد مزامنة بين الأجهزة أو ضمانات معاملات بين نوافذ تكتب في الوقت نفسه.

## التحقق

```sh
npm run test:ci
npm run lint
npm run build
```

اختبار المتصفح القابل لإعادة التشغيل موجود في `scripts/demo-flow.cjs`. يحتاج Playwright وaxe-core وخادم التطوير قيد التشغيل. يمكن توفير الأدوات خارجيًا عبر `PLAYWRIGHT_MODULE` و`AXE_SOURCE`، أو تثبيتها محليًا لأغراض الاختبار دون تغيير ملف القفل:

```sh
npm install --no-save --package-lock=false playwright axe-core
node scripts/demo-flow.cjs
```

يستخدم Microsoft Edge على Windows، وChromium على الأنظمة الأخرى. يمكن اختيار متصفح عبر `BROWSER_CHANNEL` وتغيير عنوان المشروع عبر `DEMO_BASE_URL`. عند استخدام Chromium يجب تثبيت متصفحه الخاص بـPlaywright أولًا.

الاختبار يغطي الشراء كضيف وبحساب، واسترجاع الطلب بعد تحديث الصفحة، وحفظ العنوان، والصيانة واسترجاع إيصالها، ويُخرج لقطات الكمبيوتر والموبايل وتقارير axe في `.angular`. فحص axe موجّه إلى محتوى الصفحات، وليس تدقيقًا شاملًا لكل صفحات الموقع أو كل معايير WCAG.

التحقق في 10 سبتمبر 2026: اجتازت رحلة المتصفح الشراء كضيف وبحساب، وتحديث صفحة الطلب، وحفظ الصيانة وإعادة فتح تفاصيلها. لم تُسجّل أخطاء JavaScript أو مخالفات axe في الحالات التسع المفحوصة، ولم يظهر تمدد أفقي في اللقطات المختبرة بعرض 1440 و390 بكسل.
